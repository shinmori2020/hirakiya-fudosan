## データの出どころ

- 物件:`web/data/properties/index.json`(`getProperties`)。新着は `lib/home.ts` の `latestProperties`
- 入口の件数:`lib/entries.ts` の **`coveredCounts`**(同じ物件を1回だけ数える。沿線は1物件が2本に乗るため・J-126)
- 会社の数字・声・お知らせ・店舗:`config/site.ts`(**声とお知らせは `/voice` `/news` と同じ配列**・J-056 項目9)
