# 物件詳細ページ

物件1件の情報を見せて、内見予約・問い合わせにつなげるページ。実装順 2(2026-09-09〜09-14)。

このサイトは制作の記録を残すための架空のサイト。会社名・住所・電話番号・免許番号・人名・物件はすべて架空で、番地は `0-0-0`、電話は `03-0000-0000`、免許番号は `000000` に統一している。

判断の経緯(なぜその形にしたか)は `docs/記録シート.md` の J-037〜J-094 にある。ここでは**何ができるか**だけを書く。

## 画面の構成(上から順に)

| # | 要素 | 内容 |
|---|---|---|
| 1 | パンくず | トップ > 賃貸(売買)物件を探す > 墨田区曳舟 > 物件名(4階層。町はその町で絞った一覧へ) |
| 2 | 写真ギャラリー | メイン画像+サムネイル。間取り図は最後 |
| 3 | 右カラム | 状態バッジ・種目 → 物件名 → 駅徒歩+町名 → 価格 → 毎月の費用 → 値下げ前 → 間取り・面積・階・築年 → 設備 → ボタン2つ |
| 4 | 物件データ | 開閉する3区分(入居前に確認すること / 建物 / 契約・掲載)。最初は「確認」だけ開く |
| 5 | この物件について | ポイントタグ最大3つ + 担当者のコメント(写真・氏名・役職・資格) |
| 6 | 所在地 | 地図(OpenStreetMap) |
| 7 | この物件を見てみる | 予約と問い合わせのボタン + 共有(〜1023px) |
| 8 | 同じエリア・条件の物件 | カード4件 |
| 9 | 最近見た物件 | カルーセル(見た履歴がある時だけ出る) |

PC(1024px以上)は 2・3 を左右に並べ、それより狭い幅では縦に積む。スマホは画面下に固定ボタン(電話 / LINE(ダミー)/ 内見予約)。

## 機能

**写真ギャラリー**
画像を押すと全画面で開く。左右の矢印・キーボードの ← → ・スマホの横スワイプで送れ、端まで行くと先頭に戻る。閉じるのは × ・Esc・画像の外側のクリック。サムネイルからも直接選べる。ライブラリは使わず、ブラウザ標準の `<dialog>` と CSS だけで作っている。写真が0枚の物件(60件中3件)は「写真準備中」と出し、押すと間取り図だけが開く。

**右カラム(探す段階で使う情報)**
置くのは「一覧で使われた情報」かつ「候補を外す / 残すの判断に直接使う」かつ「値だけで完結する」項目に絞っている。同じ項目を物件データと両方には出さない。

- **毎月の費用**:賃貸は「毎月」(家賃+管理費・共益費)、売買マンションは「毎月の維持費」(管理費+修繕積立金)。**値がある時だけ出す**(管理費が無い賃貸、戸建・土地は行ごと出さない)
- **スペック**:賃貸・売買マンション・戸建は 間取り / 面積 / 階 / 築年、土地は「土地 77㎡」
- **設備**:チップ(押すとその設備で絞った一覧へ)。土地は設備が無いので出ない

**物件データ(3区分)**
開閉は JavaScript を使わず `<details>` で行い、閉じていても中身は HTML に存在する(検索エンジンから見える)。見出しは h3 で、ページの見出しは h1 → h2 → h3 の順に繋がる。

| 区分 | 賃貸 | 売買 |
|---|---|---|
| 入居前に(購入前に)確認すること | 管理費・共益費 / 駐車場の状況 / 敷金 / 礼金 / 仲介手数料 / 更新料 /(区切り)/ **入居時の目安合計** | マンション = 管理費 / 修繕積立金 / 駐車場の状況 / **仲介手数料(上限)**、戸建・土地 = 駐車場の状況 / 仲介手数料(上限) |
| 建物(売買は 土地・建物) | 所在地 / 交通 / 沿線 / 築年月 / 構造 / 階数 / 向き | 所在地 / 交通 / 沿線 / 築年月 / 構造 / 階数 / 専有面積 / 建物面積 / 土地面積 / 土地権利 / 用途地域 / 建ぺい率・容積率 / 接道 / 向き(土地は築年月・構造・階数・向き・建物面積が無い) |
| 契約・掲載 | 契約期間 / 入居可能日 / 保証人 / 取引態様 / 物件番号 / 情報更新日 / 次回更新予定日 | 引渡し / 取引態様 / 物件番号 / 情報更新日 / 次回更新予定日 |

確認の区分は**まとまりの見出しを置かず、1列に時点の順**で並べる(合計は前の項目を足した結果なので最後)。建物・契約・掲載は**2列**。建物・契約・掲載は値が無くても「—」を出すが、確認の区分は**その種別に無い項目は行ごと出さない**(管理費・修繕積立金はマンションだけ)。

**入居時の目安合計(賃貸)**
家賃・管理費・敷金・礼金・仲介手数料を円に揃えて合計した金額を出し、「保証料・保険料・日割り家賃は含みません」と添える。敷金・礼金は家賃の月数、仲介手数料は選択肢の文字列なので、家賃を掛けて円に直してから足している。

**仲介手数料(売買)**
データに持たず、**価格から計算**して出す(宅地建物取引業法の上限額 = 価格の3%+6万円+消費税)。ラベルに「(上限)」を付け、「実際の額は異なる場合があります」と明記する。売買には入居時の目安合計に相当するものは作っていない(頭金・諸費用・税金のデータが無いため)。

物件データの駐車場の行は「**駐車場の状況**」(なし / 空きあり(月額) / 近隣)。右カラムの設備チップ「駐車場」は**駐車場がある物件で絞る検索条件**で、意味が違うので文言を分けている。

**予約・問い合わせ**
上下の CTA は `/contact` に飛ぶ。内見(見学)予約は `/contact?property=<物件番号>&kind=viewing` で**種別を内見希望にした状態**で開き、問い合わせは `/contact?property=<物件番号>`(種別は選ばせる)。物件は **URL のパラメータだけ**で渡し、ブラウザには持たせない。飛び先では対象物件が右カラムに出る(成約済みの物件番号が来た場合は「この物件は成約しています」として物件を指定しない問い合わせになる)。スマホの固定 CTA も同じ URL。

**一覧への回遊**
駅名・沿線・間取り・設備・町名・種目・ポイントタグ・パンくずの町を押すと、その条件で絞り込んだ物件一覧へ移動する。一覧の絞り込みに無い条件(向き・築年・面積・金額など)はリンクにしていない。

**ポイントタグ**
特集・駅徒歩・築年・設備から自動で最大3つ選んで出す。データに無い形容(閑静・人気など)は使わない。

**担当者のコメント**
物件のデータ(区・町・駅・徒歩分・築年月・構造・階数・間取り・面積・設備・費用・引渡しなど)から7文・150〜200字を組み立てている。データに無いことは書かない。写真はプレースホルダーで、実写真は使わない。

**地図**
OpenStreetMap + Leaflet。ズーム15固定・ホイール操作は無効。架空の住所なので、ピンは町の代表座標付近に置き、その旨をページに明記している。JavaScript が動かない環境では地図は出ず、住所のテキストだけが残る。

**共有(URL コピー / LINE)**
PC(1024px以上)は**画面の右下に追従**し、スクロール位置に関わらず使える。それより狭い幅は追従させず、下部の「この物件を見てみる」の中にテキストリンクで置く(スマホには固定ボタンがあるので、浮くものを2つにしない)。URL コピーは押すと「コピーしました」に変わり2秒で戻る。**JavaScript が動かない環境ではコピーのボタンを出さない**(LINE は素のリンクなので出る)。

**同じエリア・条件の物件**
同じ町 → 同じ沿線 → 同じ種別の順に4件。成約済みと自分自身は含めない。

**最近見た物件**
見た物件の番号だけをブラウザに保存(最大10件)。サーバーには送らない。PCは矢印で1件ずつ送り、スマホは横スワイプ。

**成約済みの物件**
ページを消さず、見出し+本文で「この物件は成約しました」と表示し、内見予約のボタン(画面下の固定ボタンも)を隠す。問い合わせ・共有・関連物件は残す。

**構造化データ**
`RealEstateListing`(価格・面積・住所・緯度経度・取引態様・物件番号。賃貸は月額であることを示し、掲載状態を 公開中 / 商談中 / 成約済み で出す)と `BreadcrumbList`(画面のパンくずと同じ4階層)を出力している。

**キーボードと読み上げ**
全ページの先頭に「本文へスキップ」があり、Tab の1回目で到達する(普段は見えない)。ギャラリーの拡大・アコーディオンの開閉・カルーセルの送り・ボタンはすべてキーボードで操作でき、フォーカスの枠が出る。物件写真・担当者写真・カードの画像には代替テキストが入る。

## データと生成

WordPress(ローカルのDocker)で作った架空の物件60件(賃貸40・売買20)を JSON に書き出し、ビルド時に読んで**全60ページを静的なHTMLとして生成**している。公開後にサーバー側で組み立てる処理は無い。売買の仲介手数料のように、JSON に持たず画面で計算している値もある。
