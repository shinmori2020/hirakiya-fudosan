# サイト設計図:不動産サイト(記録用サイト)

**作成日:2026-09-05**
**前提:** 制作計画 §7(18ページ+2、機能8件、OSM系地図、会員機能なし)
**会社設定(決定・2026-09-05):** 東京都葛飾区・京成線沿線。対応エリア:葛飾・江戸川・足立・墨田。沿線:京成本線・京成押上線・京成金町線・JR常磐線・JR総武線・東武スカイツリーライン。2店舗・8名・創業25年。主軸=賃貸管理(管理戸数800戸・入居率96%)。
**会社設定の反映:2026-09-06 完了**(キャッチ・強み3点は案。SHINが書き換え可)

**各ページの記述項目**
- 目的:このページで利用者に何をさせるか
- 要素:上から順に置くもの(順序も設計の一部)
- 導線:このページから次にどこへ行かせるか
- 判断ポイント:AIが決められない、または初案で外しやすい箇所(記録シート§5に対応)

## 2. 物件一覧(検索結果)

**目的:** 条件を調整しながら比較し、詳細へ進ませる。

| # | 要素 | 内容 |
|---|---|---|
| 1 | 検索条件の表示 | 現在の条件をタグ表示。個別に外せる |
| 2 | 絞り込みパネル | PC:左サイド常時表示 / スマホ:ボタンで開くドロワー |
| 3 | 件数と並び替え | 「○件」+ 新着順 / 家賃(価格)順 / 広さ順 |
| 4 | 表示切替 | 一覧 ⇄ 地図 |
| 5 | 物件カード | 写真1枚 / 物件名 / 家賃(価格)/ 間取り・面積 / 最寄駅と徒歩分 / ステータスバッジ / 築年 |
| 6 | ページネーション | 1ページ20件程度 |
| 7 | 0件時 | 「条件を1つ緩める」提案(緩める候補を自動提示)+ 近隣エリアの提案 |

**検索条件(賃貸):** エリア・沿線駅 / 家賃(上下限)/ 間取り / 駅徒歩 / 築年 / 面積 / 設備(ペット可・駐車場・オートロック等)
**検索条件(売買):** エリア・沿線駅 / 価格帯 / 種別(土地・戸建・マンション)/ 面積 / 築年 / 学区は**入れない**(02 §8-3)

**導線:** カード → 物件詳細。0件 → 緩めた条件の一覧。
**判断ポイント:**
- **検索条件をURLに同期する**(共有・戻るボタン・ブックマーク)。AIの初案はstateのみで済ませがち
- スマホの絞り込みパネルをドロワーにするか、ページ上部に折りたたむか
- カードに出す情報の優先順位(家賃を最も大きく。AIは物件名を大きくしがち)
- 地図モードで物件数が多い時の表示(クラスタリングの有無)
- 0件時の「緩める候補」をどう決めるか(条件の緩和順序)

## 4. 内見予約・問い合わせ(+確認・完了)

**目的:** 送信させる。離脱させない。

| # | 要素 | 内容 |
|---|---|---|
| 1 | 対象物件の表示 | 物件詳細から遷移した場合、物件名・家賃・写真を自動表示(引き継ぎ) |
| 2 | 種別選択 | 内見希望 / 空室確認 / 質問 |
| 3 | 希望日時 | 第1〜第2希望(日付+時間帯) |
| 4 | 連絡先 | 氏名 / ふりがな / 電話 / メール / 希望連絡方法(電話・メール・LINE) |
| 5 | 備考 | 任意 |
| 6 | プライバシーポリシー同意 | チェック必須 |
| 7 | 送信ボタン | → 確認画面 → 完了画面 |
| 完了 | 完了画面 | 「営業時間内に折り返し」の目安時間 / 電話番号 / 他の物件を見る導線。**架空サイトである旨をここでも明示** |

**実在の人が送信した場合の扱い(決定・2026-09-05):ダミーと分かるように設定する**
- フォーム上部に「このサイトは制作記録用の架空サイトです。送信内容は実際の対応には使われません」を表示
- 送信後の自動返信にも同じ文言を入れる
- 送信データはSHIN宛のみに届け、保存しない(DBに残さない)
- プライバシーポリシーの記述をこれに合わせる(取得する情報 / 保存しない旨 / 架空サイトである旨)
- 査定フォーム・管理相談フォームも同じ扱い

**判断ポイント:**
- 項目数(多いと離脱。必須は氏名・電話・希望日時に絞る)
- 確認画面を挟むか(不動産は挟むのが慣習)
- 送信先・自動返信・迷惑メール判定・スパム対策(章3)
- 二重送信防止、送信中の表示、エラー時の表示
- 物件情報の引き継ぎをURLパラメータで行うか、ブラウザ側で持つか

## フォームの整理(3種+共通)

| フォーム | 置き場所 | 固有項目 | 共通項目 |
