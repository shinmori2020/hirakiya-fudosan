# 制作記録シート:不動産サイト(記録用サイト)

**目的:** AIを使って一からWEBサイトを制作し、その経緯・意図・判断をすべて記録する。完成物ではなく記録を成果物とし、AIを活用できる人材であることの証明に使う。

**運用ルール(制作計画 §3 より)**
- 記録するのは**判断が発生した瞬間だけ**。AIの案をそのまま採用して問題がなかった箇所は「そのまま採用」と1行のみ
- 判断ログは「AIの初案 → 自分の判断 → 修正後」の3点セット。**判断の出所**を必ず書く
- スクリーンショットは撮り逃すと復元不可(デザイン初案・崩れた表示・エラー画面)。ファイル名を記録に書く
- AIとの会話ログが一次記録。後から抽出できるので、ここには要点だけ書く
- 上限時間に達したら制作を止めて記録を仕上げる。埋まらなかった章は「未通過」と書く

**コミットとスクリーンショットの規約(2026-09-05 決定)**
- コミットメッセージは Conventional Commits(`feat:` `fix:` `docs:` `refactor:`)。**判断を伴うコミットは末尾に `[J-ID]`** を付ける。例:`feat: add search url sync [J-021]`。判断を伴わないコミットには付けない
- スクリーンショットは `docs/screenshots/` に置き、`J-ID-before.png` / `J-ID-after.png`。同じ判断に複数ある時は `-before-2` `-after-2`
- 本シートと設計図・制作計画は `docs/` 配下に置き、Git管理する(Nordic Works と同じ構成)
